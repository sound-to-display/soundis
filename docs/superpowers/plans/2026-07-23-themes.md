# Soundis Theme System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the single hardcoded visualizer with a 5-theme system (RING / HORIZON / CONSOLE / SCOPE / ARCADE), a bottom theme selector with keyboard shortcuts, per-theme UI reskinning via CSS variables, dip-through transitions, idle animations, and a hiddenInset window frame.

**Architecture:** Each theme is an independent module implementing `{ id, name, palette, create(container) → { update(frame), resize(w,h), dispose() } }` and owns its own canvas (Three.js or 2D — theme's choice). A new `renderer/stage.js` owns the rAF loop, frame assembly, theme lifecycle, the transition overlay, palette→CSS-variable application, and the single window resize listener. `renderer/renderer.js` shrinks to control wiring. `renderer/visualizer.js` is deleted (its ring scene moves to `renderer/themes/ring.js`).

**Tech Stack:** Electron ^43.2.0, Three.js ^0.185.1 (RING, HORIZON only), 2D canvas (CONSOLE, SCOPE, ARCADE), Node built-in `node --test`.

## Global Constraints

- `AnalyserNode.fftSize` stays `512`; waveform array length = fftSize (512 samples).
- Fonts stay monospace across all themes (`'SF Mono', Menlo, Consolas, monospace`).
- `nodeIntegration: true` / `contextIsolation: false` unchanged. No server round-trips. No new npm dependencies.
- Existing audio error handling is untouched: exact Korean messages, no automatic source fallback, `activeSource` restore on failed switch.
- `frame` object contract (single object reused every frame, no per-frame allocation): `{ bass, mid, treble, level, bins, waveform, time, dt }` — bass/mid/treble/level normalized 0–1; `bins` `Uint8Array(256)` raw frequency data (0–255, the analyser's `frequencyBinCount` array, same one `getBandEnergies()` fills); waveform `Uint8Array(512)` time-domain (128 = silence center); time/dt in seconds.
- Every theme MUST look alive at `level ≈ 0` using `time` (gentle idle motion). No separate idle mode.
- Theme palettes (bg / accent / dim), exact values:
  - ring: `#0a0a0a` / `#e0a458` / `#5a4a38`
  - horizon: `#12081f` / `#ff4fd8` / `#5a3a7a`
  - console: `#241a12` / `#e8873a` / `#7a5c40`
  - scope: `#050805` / `#4dff6a` / `#1d5a28`
  - arcade: `#10122b` / `#ffd23e` / `#4a4e8a`
- Registry order (selector + number keys 1–5): ring, horizon, console, scope, arcade.
- Transition: 250ms fade to next theme's `bg`, swap, 250ms fade back. `setTheme` calls during a transition are ignored.
- Theme `create()` failure: log `console.error`, remount previous theme, show status `테마 전환에 실패했습니다. 콘솔을 확인해주세요.`
- No external test framework — `node --test` only. Theme modules must be require-able in plain Node (browser APIs only inside `create()` bodies).

- [ ] **Step 3: Write the RING theme**

Create `renderer/themes/ring.js` (a port of the existing `renderer/visualizer.js` scene to the theme interface — bass/mid/treble now arrive pre-normalized 0–1, so the `/255` normalization is gone; a subtle time-based breath is added for idle; dispose fully tears down):

```js
const THREE = require('three');

const PARTICLE_COUNT = 200;
const BASE_RADIUS = 2;

module.exports = {
  id: 'ring',
  name: 'RING',
  palette: { bg: '#0a0a0a', accent: '#e0a458', dim: '#5a4a38' },

  create(container) {
    const amber = new THREE.Color(0xe0a458);

    const scene = new THREE.Scene();
    scene.background = new THREE.Color(0x0a0a0a);

    const camera = new THREE.PerspectiveCamera(
      60,
      container.clientWidth / container.clientHeight,
      0.1,
      100
    );
    camera.position.z = 6;

    const renderer = new THREE.WebGLRenderer({ antialias: true });
    renderer.setPixelRatio(window.devicePixelRatio);
    renderer.setSize(container.clientWidth, container.clientHeight);
    container.appendChild(renderer.domElement);

    const group = new THREE.Group();
    group.rotation.x = 0.4;
    scene.add(group);

    const basePositions = new Float32Array(PARTICLE_COUNT * 3);
    const positions = new Float32Array(PARTICLE_COUNT * 3);
    const colors = new Float32Array(PARTICLE_COUNT * 3);

    for (let i = 0; i < PARTICLE_COUNT; i++) {
      const angle = (i / PARTICLE_COUNT) * Math.PI * 2;
      basePositions[i * 3] = Math.cos(angle) * BASE_RADIUS;
      basePositions[i * 3 + 1] = Math.sin(angle) * BASE_RADIUS;
      basePositions[i * 3 + 2] = 0;
      positions[i * 3] = basePositions[i * 3];
      positions[i * 3 + 1] = basePositions[i * 3 + 1];
      positions[i * 3 + 2] = 0;
      colors[i * 3] = amber.r;
      colors[i * 3 + 1] = amber.g;
      colors[i * 3 + 2] = amber.b;
    }

    const geometry = new THREE.BufferGeometry();
    geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));
    geometry.setAttribute('color', new THREE.BufferAttribute(colors, 3));

    const material = new THREE.PointsMaterial({ size: 0.08, vertexColors: true });
    group.add(new THREE.Points(geometry, material));

    return {
      update(frame) {
        const breath = 0.03 * Math.sin(frame.time * 0.8);
        const radiusScale = 1 + frame.bass * 0.6 + breath;
        group.rotation.z += 0.01 + frame.mid * 0.08;

        const posAttr = geometry.attributes.position;
        const colorAttr = geometry.attributes.color;
        const brightness = 0.6 + frame.treble * 0.4;
        const jitterAmount = frame.treble * 0.15;

        for (let i = 0; i < PARTICLE_COUNT; i++) {
          posAttr.array[i * 3] =
            basePositions[i * 3] * radiusScale + (Math.random() - 0.5) * jitterAmount;
          posAttr.array[i * 3 + 1] =
            basePositions[i * 3 + 1] * radiusScale + (Math.random() - 0.5) * jitterAmount;
          colorAttr.array[i * 3] = amber.r * brightness;
          colorAttr.array[i * 3 + 1] = amber.g * brightness;
          colorAttr.array[i * 3 + 2] = amber.b * brightness;
        }
        posAttr.needsUpdate = true;
        colorAttr.needsUpdate = true;

        renderer.render(scene, camera);
      },

      resize(w, h) {
        camera.aspect = w / h;
        camera.updateProjectionMatrix();
        renderer.setSize(w, h);
      },

      dispose() {
        geometry.dispose();
        material.dispose();
        renderer.dispose();
        renderer.domElement.remove();
      },
    };
  },
};
```

### Task 3: Stage (lifecycle, rAF loop, transitions, palette)

**Files:**
- Create: `renderer/stage.js`

**Interfaces:**
- Consumes: `require('./themes/index.js')` array (Task 2).
- Produces: `createStage(container, { getFrame, onThemeChange, onThemeError })` returning `{ themes, currentIndex (getter), setTheme(index), next(), prev() }`.
  - `getFrame()` must return the frame object with `bass/mid/treble/level/waveform` filled; stage fills `time`/`dt` itself.
  - `onThemeChange(theme, index)` fires after every successful mount (including the initial one).
  - `onThemeError(theme)` fires when a theme's `create()` throws.
- Consumed by `renderer.js` (Task 4). The `.stage-overlay` CSS class is styled in Task 4's `style.css`.

- [ ] **Step 1: Write `renderer/stage.js`**

```js
const themes = require('./themes/index.js');

const TRANSITION_MS = 250;

function createStage(container, { getFrame, onThemeChange, onThemeError }) {
  let currentIndex = -1;
  let active = null;
  let transitioning = false;

  const overlay = document.createElement('div');
  overlay.className = 'stage-overlay';
  container.appendChild(overlay);

  function applyPalette(palette) {
    const root = document.documentElement;
    root.style.setProperty('--bg', palette.bg);
    root.style.setProperty('--accent', palette.accent);
    root.style.setProperty('--dim', palette.dim);
  }

  function mount(index) {
    const theme = themes[index];
    active = theme.create(container);
    container.appendChild(overlay); // re-append so the overlay stays above the new canvas
    applyPalette(theme.palette);
    currentIndex = index;
    onThemeChange(theme, index);
  }

  function fade(toOpacity) {
    return new Promise((resolve) => {
      overlay.addEventListener('transitionend', resolve, { once: true });
      setTimeout(resolve, TRANSITION_MS + 150);
      requestAnimationFrame(() => {
        overlay.style.opacity = String(toOpacity);
      });
    });
  }

  async function setTheme(index) {
    if (transitioning || index === currentIndex || index < 0 || index >= themes.length) {
      return;
    }
    transitioning = true;
    const prevIndex = currentIndex;
    overlay.style.background = themes[index].palette.bg;
    await fade(1);
    if (active) {
      active.dispose();
      active = null;
    }
    try {
      mount(index);
    } catch (error) {
      console.error('[stage] Theme mount failed:', error);
      onThemeError(themes[index]);
      try {
        mount(prevIndex);
      } catch (fallbackError) {
        console.error('[stage] Fallback remount failed:', fallbackError);
      }
    }
    await fade(0);
    transitioning = false;
  }

  let lastTime = performance.now();
  function tick(now) {
    requestAnimationFrame(tick);
    const dt = Math.min((now - lastTime) / 1000, 0.1);
    lastTime = now;
    if (!active) return;
    const frame = getFrame();
    frame.time = now / 1000;
    frame.dt = dt;
    active.update(frame);
  }

  window.addEventListener('resize', () => {
    if (active) {
      active.resize(container.clientWidth, container.clientHeight);
    }
  });

  mount(0);
  requestAnimationFrame(tick);

  return {
    themes: themes.map((t) => ({ id: t.id, name: t.name })),
    get currentIndex() {
      return currentIndex;
    },
    setTheme,
    next() {
      setTheme((currentIndex + 1) % themes.length);
    },
    prev() {
      setTheme((currentIndex - 1 + themes.length) % themes.length);
    },
  };
}

module.exports = { createStage };
```

const { AudioSourceManager } = require('./audio.js');
const { createStage } = require('./stage.js');

const manager = new AudioSourceManager({ fftSize: 512 });

const statusEl = document.getElementById('status');
const micBtn = document.getElementById('btn-mic');
const systemBtn = document.getElementById('btn-system');
const themeNameEl = document.getElementById('theme-name');
const themePrevBtn = document.getElementById('btn-theme-prev');
const themeNextBtn = document.getElementById('btn-theme-next');

let activeSource = null;

function setStatus(text) {
  statusEl.textContent = text;
}

function setActiveButton(source) {
  micBtn.classList.toggle('active', source === 'mic');
  systemBtn.classList.toggle('active', source === 'system');
}

const frameData = {
  bass: 0, mid: 0, treble: 0, level: 0, bins: null, waveform: null, time: 0, dt: 0,
};

function getFrame() {
  const energies = manager.getBandEnergies();
  frameData.bass = energies.bass / 255;
  frameData.mid = energies.mid / 255;
  frameData.treble = energies.treble / 255;
  frameData.level = (frameData.bass + frameData.mid + frameData.treble) / 3;
  frameData.bins = manager.dataArray; // freshly filled by getBandEnergies() above
  frameData.waveform = manager.getWaveform();
  return frameData;
}

const stage = createStage(document.getElementById('canvas-container'), {
  getFrame,
  onThemeChange(theme) {
    themeNameEl.textContent = theme.name;
  },
  onThemeError() {
    setStatus('테마 전환에 실패했습니다. 콘솔을 확인해주세요.');

});

micBtn.addEventListener('click', async () => {

  }
});

window.addEventListener('keydown', (event) => {

const THREE = require('three');

const GRID_W = 60;
const GRID_D = 80;
const SEG_X = 48;
const SEG_Z = 64;

function makeSkyTexture() {
  const canvas = document.createElement('canvas');
  canvas.width = 4;
  canvas.height = 256;
  const ctx = canvas.getContext('2d');
  const grad = ctx.createLinearGradient(0, 0, 0, 256);
  grad.addColorStop(0, '#12081f');
  grad.addColorStop(0.55, '#2b1244');
  grad.addColorStop(0.78, '#7a2a6a');
  grad.addColorStop(1, '#c4407a');
  ctx.fillStyle = grad;
  ctx.fillRect(0, 0, 4, 256);
  return new THREE.CanvasTexture(canvas);
}

function makeSunTexture() {
  const size = 256;
  const canvas = document.createElement('canvas');
  canvas.width = size;
  canvas.height = size;
  const ctx = canvas.getContext('2d');
  const grad = ctx.createLinearGradient(0, 0, 0, size);

  grad.addColorStop(0.55, '#ff8a3e');

  }

}

function ridge(x, z) {
  const corridor = Math.min(Math.abs(x) / 8, 1);
  const n =
    Math.abs(Math.sin(x * 0.35 + Math.sin(z * 0.21) * 1.7) * Math.cos(z * 0.13));
  return n * corridor * corridor;
}

  const canvas = document.createElement('canvas');
  canvas.style.display = 'block';
  container.appendChild(canvas);
  const ctx = canvas.getContext('2d');

  const state = { canvas, ctx, width: 0, height: 0 };

  state.resize = (w, h) => {

    canvas.width = Math.round(w * dpr);
    canvas.height = Math.round(h * dpr);

const SPRING_K = 120;
const SPRING_D = 8;

function stepNeedle(state, target, dt) {
  const accel = SPRING_K * (target - state.angle) - SPRING_D * state.velocity;
  state.velocity += accel * dt;
  state.angle += state.velocity * dt;
  return state;
}

function drawDialFace(ctx, cx, cy, radius) {
  ctx.save();
  ctx.translate(cx, cy);

  ctx.fillStyle = '#efe3c8';
  ctx.beginPath();
  ctx.arc(0, 0, radius, Math.PI, 0);
  ctx.lineTo(radius, radius * 0.28);
  ctx.lineTo(-radius, radius * 0.28);
  ctx.closePath();
  ctx.fill();

  const startAngle = -Math.PI * 0.75;
  const endAngle = -Math.PI * 0.25;
  for (let i = 0; i <= 10; i++) {
    const t = i / 10;
    const a = startAngle + (endAngle - startAngle) * t;
    const inner = radius * 0.72;
    const outer = radius * (i % 5 === 0 ? 0.82 : 0.78);
    ctx.strokeStyle = t > 0.75 ? '#c0392b' : '#3a2c1a';
    ctx.lineWidth = i % 5 === 0 ? 2 : 1;
    ctx.beginPath();
    ctx.moveTo(Math.cos(a) * inner, Math.sin(a) * inner);
    ctx.lineTo(Math.cos(a) * outer, Math.sin(a) * outer);
    ctx.stroke();
  }

  ctx.strokeStyle = '#c0392b';
  ctx.lineWidth = 3;
  ctx.beginPath();
  ctx.arc(0, 0, radius * 0.85, startAngle + (endAngle - startAngle) * 0.78, endAngle);
  ctx.stroke();

  ctx.fillStyle = '#3a2c1a';
  ctx.font = `${Math.round(radius * 0.14)}px 'SF Mono', Menlo, monospace`;
  ctx.textAlign = 'center';
  ctx.fillText('VU', 0, -radius * 0.3);

  ctx.restore();
}

Create `renderer/themes/arcade.js`. 24 chunky pixel bars quantized into 16 block rows, NES-ish color steps by height, gravity-falling peak caps, bass bounces the whole field, snappy-rise/smooth-fall bar ballistics, idle ripple across bars.

```js
const { createCanvas2d } = require('./canvas2d.js');

const BAR_COUNT = 24;
const BLOCK_ROWS = 16;
const ROW_COLORS = ['#3ec54b', '#3ec54b', '#a7d32c', '#ffd23e', '#ff9130', '#ff4b4b'];

function binsToBars(dataArray, out) {
  const usable = Math.floor(dataArray.length * 0.75);
  const groupSize = usable / out.length;
  for (let bar = 0; bar < out.length; bar++) {
    const start = Math.floor(bar * groupSize);
    const end = Math.floor((bar + 1) * groupSize);
    let sum = 0;
    for (let i = start; i < end; i++) sum += dataArray[i];
    out[bar] = end > start ? sum / (end - start) / 255 : 0;
  }
  return out;
}

function rowColor(rowIndex) {
  const t = rowIndex / (BLOCK_ROWS - 1);
  return ROW_COLORS[Math.min(Math.floor(t * ROW_COLORS.length), ROW_COLORS.length - 1)];
}

  id: 'arcade',
  name: 'ARCADE',

  binsToBars,

  create(container) {
    const surface = createCanvas2d(container);

    const targets = new Float32Array(BAR_COUNT);
    const displayed = new Float32Array(BAR_COUNT);
    const caps = new Float32Array(BAR_COUNT);
    const capVelocities = new Float32Array(BAR_COUNT);

    return {
      update(frame) {
        const { ctx, width: w, height: h } = surface;

        // Real spectrum: downsample the analyser's raw frequency bins,
        // boost (byte bins rarely peak), and keep an idle ripple floor.
        binsToBars(frame.bins, targets);
        for (let i = 0; i < BAR_COUNT; i++) {
          const idle = 0.03 + 0.02 * Math.sin(frame.time * 2 + i * 0.5);
          targets[i] = Math.min(Math.max(targets[i] * 1.6, idle), 1);
        }

        for (let i = 0; i < BAR_COUNT; i++) {
          if (targets[i] > displayed[i]) {
            displayed[i] = targets[i];
          } else {
            displayed[i] = Math.max(displayed[i] - frame.dt * 1.6, targets[i]);
          }
          if (displayed[i] >= caps[i]) {
            caps[i] = displayed[i];
            capVelocities[i] = 0;
          } else {
            capVelocities[i] += frame.dt * 1.8;
            caps[i] = Math.max(caps[i] - capVelocities[i] * frame.dt, displayed[i]);
          }
        }

        ctx.fillStyle = '#10122b';
        ctx.fillRect(0, 0, w, h);

        const bounce = frame.bass * 10 + 2 * Math.sin(frame.time * 1.4);
        const fieldW = Math.min(w * 0.86, 900);
        const gap = 4;
        const barW = (fieldW - gap * (BAR_COUNT - 1)) / BAR_COUNT;
        const blockH = Math.min((h * 0.6) / BLOCK_ROWS, barW * 0.5);
        const blockGap = 2;
        const baseY = h * 0.82 - bounce;
        const startX = (w - fieldW) / 2;

        for (let bar = 0; bar < BAR_COUNT; bar++) {
          const litRows = Math.round(displayed[bar] * BLOCK_ROWS);
          const x = startX + bar * (barW + gap);
          for (let row = 0; row < litRows; row++) {
            ctx.fillStyle = rowColor(row);
            ctx.fillRect(
              x,
              baseY - (row + 1) * (blockH + blockGap),
              barW,
              blockH
            );
          }
          const capRow = caps[bar] * BLOCK_ROWS;
          ctx.fillStyle = '#ffffff';
          ctx.fillRect(
            x,
            baseY - (capRow + 1) * (blockH + blockGap),
            barW,
            Math.max(blockH * 0.4, 3)
          );
        }
      },

      resize(w, h) {
        surface.resize(w, h);
      },

      dispose() {
        surface.dispose();
      },
    };
  },
};
```
